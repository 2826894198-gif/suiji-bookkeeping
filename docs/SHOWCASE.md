# 随记 · 个人记账与预算管理 · 项目展示

## 一句话介绍

一笔记账，联动预算、账户和消费趋势；账本有版本，误操作能恢复。

## 项目价值

把日常记账、周期预算、父子账户和消费统计做成可用的原生微信产品，并以恢复点、版本化云同步与更新前备份保护个人账本。

## 最值得展示的能力

- 收支、回款、账簿转账、两级分类、周期预算和消费统计
- 父子账户、余额调整与账户卡片交互
- 整数分金额与跨日期统计规则

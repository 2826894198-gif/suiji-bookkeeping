## 当前操作：免费备案

1. 手机“设置 → 云端账本 → 立即同步”，核对显示“本机与云端一致”；再从“导出备份”另存一份 JSON 到自己的文件位置。模拟器已有备份不能代替这份手机独立备份。
2. 使用同一个小程序后台（AppID `YOUR_WECHAT_APPID`），从首页“小程序备案”区域进入备案。沿用原账号主体；若原账号为个人，按本人信息填写，不新注册账号或迁移主体。
3. 名称采用平台实际核准的“随记”；如未完成名称设置、名称重复或需先补基本信息，按当前页面核验后处理，不虚填名称。
4. 服务内容可填写：“个人记账工具，用于记录日常收支、安排周期预算、管理手动录入的记账账户，并提供账本备份与个人云同步。” 具体服务类目以后台真实可选项为准；没有读取列表前不指定不存在的类目名称。
5. 主办者/负责人姓名、证件、联系方式和地址由本人直接填写官方页面，完成页面要求的身份及短信核验。备案信息与承诺须本人核对，不能伪造主体、地址或备案号。
6. 提交后等平台及管局的备案结果；备案通过后，再完成隐私指引等平台要求并提交已上传的 1.0.0 审核。代码审核通过后才执行正式发布与手机数据核对。

备案审批本身不收费，依据[通信管理局办事指南](https://hunca.miit.gov.cn/bsfw/bszn/art/2024/art_7ef0d8bd3b0d433ba4b9b277f883f74d.html)；微信小程序应在微信公众平台办理，依据[腾讯云备案 FAQ](https://cloud.tencent.com/document/faq/243/97691)。不为此购买域名、云服务器、付费认证、代办或新套餐。若微信当前流程出现必须收费的门槛，先记录实际要求，不付款，也不宣称整条正式发布链路已免费完成。备案期间继续沿用原个人账本，不清理本机数据。

## 不变的数据身份

- AppID：`YOUR_WECHAT_APPID`。
- 云环境：`YOUR_CLOUD_ENV_ID`。
- 云函数：`pearlLedgerSync`；集合 `pearl_cloud_v1`，本轮不重新部署或调整权限。
- 账本键：`pearl_ledger_v1`，schema 2；同步键：`pearl_cloud_sync_v1`；更新标记：`pearl_app_release_v1`。
- 预览、体验、正式版本使用同一环境，不按版本类型切换账本。服务端继续只信任微信上下文 APPID/OPENID，原账本按原微信身份隔离；不把个人账目打入代码包。
- 本轮没有清空本地存储、重建账本、切换微信身份或迁移到新 AppID。更名不会更改这些身份。

正式版入口不是“仅管理员能打开”的发行通道。本轮保留按微信身份隔离的账本权限及页面搜索禁用规则；没有把原账本对其他身份开放。平台整体搜索开关及实际可发现性需要后台核验，不能仅凭 sitemap 宣称关闭小程序搜索。

## 自动更新与数据保护

微信负责检查和下载正式新版本；下载就绪后显示“重启更新 / 稍后”。不自动中断正在编辑的内容。提示显示前创建升级恢复点，确认重启时再次备份最新账本；任一次备份失败均不调用重启更新。下载失败保留原账本并提示下次打开重试。

新版本首次启动继续创建升级恢复点。没有修改账本或同步设置的键，也不清除待上传的操作标识。关闭小程序与清理微信数据不是同一件事；不要用清理微信数据来刷新代码。

设置页显示 `随记 · v1.0.0 · 开发版/体验版/正式版`，版本类型来自微信运行环境，不能只凭版本号宣称已经上线。增加微信原生隐私保护指引入口；后台尚未配置或当前环境无法打开时会说明失败，不能把按钮存在当作隐私配置已完成。

隐私配置据实填写：

- 本机内容：手动输入的收支金额、日期时间、备注、分类、预算及记账账户名称/余额。
